# Display Control

Мини-утилита для macOS, управляющая Acer Nitro XV282K KV через DDC/CI по USB-C / DisplayPort Alt Mode.

В комплекте:

- приложение в строке меню;
- настройка запуска приложения при входе в macOS;
- регулировка подсветки (аппаратной яркости) от 0 до 100% с проверкой применения;
- CLI `acerctl` для скриптов, Shortcuts, Raycast и автоматизации;
- переключение видеовходов USB-C, DisplayPort, HDMI 1 и HDMI 2;
- два KVM-профиля: «Этот Mac» и «Второй PC», переключающие видео и USB-хаб одним действием;
- логическое отключение Acer в macOS для профиля «Второй PC», чтобы окна и курсор не оставались на невидимом экране;
- переключение USB-upstream между USB-C и USB-B через добавленный VCP-код `EA`.

## Требования

- Apple Silicon Mac;
- macOS 14 или новее;
- DDC/CI включён в OSD монитора;
- прямое подключение монитора по USB-C / DP Alt Mode.
- для управления USB-хабом — установленная и проверенная прошивка XV282K KV V11.

## Установка и обновления

Скачайте DMG для Apple Silicon из [последнего релиза](https://github.com/NikoVonLas/display-control/releases/latest), перенесите приложение в «Программы» и запустите. Публичная сборка имеет подпись ad hoc и не проходит нотариализацию Apple.

В «Настройки» → «Обновления» можно включить автоматическую проверку и установку, посмотреть текущую версию или проверить обновления вручную. При включённой автопроверке Sparkle обращается к GitHub примерно раз в час. Лента и образ приложения проверяются по открытому ключу проекта. Прошивка монитора обновляется отдельно.

DDC-команды выполняются локально. Для чтения датчиков приложение подключается к серверу Home Assistant, указанному в настройках.

## Сборка приложения

```bash
git clone https://github.com/NikoVonLas/display-control.git
cd display-control
./scripts/build-app.sh
```

Результат появится здесь:

```text
dist/Display Control.app
dist/acerctl
```

Перенесите приложение в `/Applications`, запустите его и включите переключатель
«Запускать при входе» в окне «Настройки» на вкладке «Расширенные». После этого утилита будет появляться
в строке меню при входе в macOS. Выключение переключателя отменяет автозапуск.
Если macOS потребует подтверждение, панель покажет подсказку и кнопку перехода
в системные «Объекты входа». Настройка отражает системное состояние, в том числе
после изменений через настройки macOS.

Скрипт сборки использует единственный доступный сертификат Apple Development.
При нескольких сертификатах задайте нужный в `ACER_SIGN_IDENTITY`. После
перехода с временной подписи macOS может потребовать один раз добавить
установленную копию приложения заново в «Универсальном доступе».

## CLI

```bash
# Найти дисплеи
./dist/acerctl list

# Яркость подсветки
./dist/acerctl get brightness
./dist/acerctl set brightness 70

# Прочитать текущий вход
./dist/acerctl get input

# Переключить видео и USB-хаб одной командой
./dist/acerctl profile mac
./dist/acerctl profile pc dp
./dist/acerctl profile pc hdmi1

# Переключить вход
./dist/acerctl set input usb-c
./dist/acerctl set input dp
./dist/acerctl set input hdmi1
./dist/acerctl set input hdmi2

# Переключить только USB-upstream (требует прошивку V11)
./dist/acerctl set hub usb-c
./dist/acerctl set hub usb-b

# Прочитать или записать произвольный VCP-регистр
./dist/acerctl get vcp 0x60
./dist/acerctl set vcp 0x60 0x10
```

Для XV282K KV USB-C определяется монитором как `0x10`, то есть внутренний второй DisplayPort. Остальные значения: DP `0x0F`, HDMI 1 `0x11`, HDMI 2 `0x12`.

## Подсветка

Ползунок «Подсветка» управляет яркостью панели через VCP `10`, а не программным
затемнением картинки. Проценты пересчитываются в диапазон, сообщённый монитором.
Яркость запоминается отдельно для «Этот Mac» (USB-C) и «Второй PC» (DP/HDMI),
сохраняется между перезапусками и восстанавливается при переключении. При
первом посещении PC используется текущая яркость Mac; затем у каждого
компьютера свой уровень. Приложение сохраняет выбор ползунка после проверки фактического входа
и результата записи. Если профиль переключили во время задержки ползунка,
выбор сохраняется для подтверждённого исходного входа. После восстановления
связи с монитором приложение проверяет яркость и на прежнем входе. В течение 10 секунд после переключения
приложение проверяет, сбросил ли монитор яркость. Для восстановления нужны
два одинаковых замера на выбранном входе. Если яркость уже нужная, команда
не отправляется. После подтверждённой записи повторные коррекции прекращаются.
Недоступный ответ DDC не превращается в 0% и не затирает сохранённый уровень.
Намеренно выставленные ползунком 0% поддерживаются.

Изменения объединяются с задержкой 250 мс, чтобы не перегружать DDC во время
перетаскивания. После записи значение считывается обратно. Если HDR или режим
изображения блокирует регулировку, приложение показывает ошибку; если яркость
не удаётся прочитать, ползунок недоступен.

Команды CLI `profile` переключают только видео и хаб. Удаление рабочего стола
macOS и его фоновое восстановление обслуживает запущенное приложение.

## Освещение и автоматизации (0.4.0)

Откройте «Настройки» → «Освещение». Новые режимы изначально
выключены. Выберите переход по местным часам (45 минут от указанного часа)
или по солнцу (введите широту и долготу города). Утром и вечером по высоте
солнца от −6° до +6° плавно меняется яркость. Дневной
и ночной уровни задаются отдельно. Отрицательная яркость до −90% на Mac
оставляет подсветку на аппаратном минимуме и затемняет изображение прозрачным
слоем. Для цветовой температуры используется штатный Night Shift macOS.
Во вкладке «Освещение» можно включить его и изменить теплоту. Расписание
по часам или от заката до рассвета задаётся в «Системные настройки → Дисплеи →
Night Shift» и продолжает действовать после выхода из приложения. Если версия
macOS не поддерживает прямое управление, доступна кнопка системных настроек.

Синхронизация связывает Acer с первым активным внешним монитором из списка macOS. На входе Mac изменение аппаратной яркости любого из двух мониторов передаётся второму. Когда Acer показывает PC, второй монитор сохраняет уровень Mac.

Если второй монитор игнорирует запись по DDC, приложение затемняет его программно и через минуту повторяет проверку аппаратной регулировки. Ползунок «Второй монитор при 0% Acer» задаёт долю собственной подсветки, которая останется при нуле на Acer. Ниже нуля оба экрана затемняются дополнительно.

### Home Assistant

В настройках откройте «Датчики». В блоке Home Assistant нажмите «Подключить»
и введите адрес HA и токен. Токен сохраняется в Связке ключей Mac с привязкой
к серверу. Кнопка «Настроить подключение» открывает эти параметры повторно.
Чтобы использовать показания источников для управления яркостью, во вкладке
«Освещение» включите «Учитывать освещённость» в разделе «Автояркость».

Добавьте нужные датчики и лампы с этого сервера. Нажмите «Выбрать» для поиска
по имени или введите ID сущности. Для каждого датчика доступен автоматический
перевод из lx, klx или fc либо собственные пары «показание → лк». Для лампы
можно задать пары «яркость в процентах → лк» либо освещённость при полном
тёплом и холодном белом с поправкой на цвет. Между своими точками используется
линейная интерполяция; за пределами таблицы действует крайнее значение.
Выключенная лампа даёт 0 лк.

Приложение подписывается на изменения настроенных источников, сверяет их
состояние каждые 30 секунд и использует максимум из доступных значений в люксах.
При потере подписки оно временно переходит на опрос.
В «Яркость по освещённости» добавьте точки с освещённостью в люксах и яркостью
от −90 до 100%, затем нажмите «Сохранить». Между соседними точками яркость
меняется по логарифмической шкале освещённости, за краями списка действует
ближайшая точка. Если включено расписание, оно ограничивает верхнюю границу. Через пять минут без успешного
чтения действует расписание. Если расписание выключено, автоматические записи
яркости приостанавливаются.

### Команды для скриптов и «Команд» macOS

Эти команды отправляются уже запущенному приложению в сеансе пользователя.
В «Командах» выберите «Запустить shell-скрипт». Путь к CLI установленной копии:

```sh
ctl='/Applications/Display Control.app/Contents/Resources/bin/acerctl'
"$ctl" lighting status             # JSON о состоянии
"$ctl" lighting sync on            # синхронизировать два экрана
"$ctl" lighting brightness 30 45   # вручную 30%, пауза автояркости Mac на 45 мин
"$ctl" lighting pause 60           # приостановить автояркость на час
"$ctl" lighting resume             # вернуться к расписанию и датчику
"$ctl" lighting lux 120            # передать замер локальным скриптом
```

Статус не меняет настройки. Команда brightness возвращает успех после
подтверждения Acer. Остальные настройки применяются в цикле опроса. Ползунок
и клавиши при включённой автояркости дают ручной приоритет на один час.
Обычная команда `acerctl set brightness 70` использует тот же путь при запущенном
приложении. При закрытом приложении она сохраняет прежний прямой режим DDC.

## Штатная яркость macOS

В протестированной конфигурации XV282K KV штатный ползунок macOS был доступен в HDR. В SDR приложение регулирует аппаратную подсветку через DDC.

С версии 0.3.2 клавиши яркости управляют аппаратной подсветкой Acer через DDC
без HDR, когда выбран Mac. Шаг — 6,25%, с Shift+Option — 1%. Для работы
нужно разрешить Display Control в «Универсальном доступе» macOS; кнопка
«Запросить доступ…» и статус клавиш находятся в «Настройки» → «Расширенные». Кнопка вызывает системный запрос. Приложение проверяет разрешение при возврате в окно и каждые две секунды. Без разрешения
ползунок приложения работает как раньше. На входе PC клавиши не перехватываются.

## USB Port Select

Acer не реализовал публичную DDC-команду для `USB Port Select`. Прошивка V11
добавляет для него читаемый и записываемый VCP-код `EA`. Фактическое поведение
проверено на XV282K KV:

- `EA=0` — upstream USB-B / B-Type;
- `EA=1` — upstream USB-C / C-Type.

Штатная прошивка безопасно игнорирует `EA`, но USB-хаб на ней не переключится.
В [архиве V007](windows-flash-bundle/START-HERE.md) сохранены заводской образ, Windows-прошивальщик и ранний экспериментальный патч. У раннего патча другая схема EA и нет чтения маршрута. Он несовместим с управлением хабом в этой версии приложения. Для регулировки яркости и выбора видеовхода достаточно штатной прошивки.

V11 поддерживает Get-VCP `EA`, поэтому приложение читает фактический маршрут
хаба при обновлении состояния. Приложение автоматически
перечитывает `VCP 60`, `EA` и яркость `10` каждые две секунды, включая время,
когда меню закрыто. Если монитор сам возвращается с
неактивного входа, схема маршрута и выделенная кнопка обновляются автоматически.
Приложение удерживает уже открытый DDC-транспорт: если macOS уберёт Acer из
списка online-дисплеев после переключения на PC, работающий процесс всё равно
попытается отправить команду возврата на USB-C.

По умолчанию профиль «Второй PC» также убирает Acer из активной конфигурации
дисплеев macOS. Окна переезжают на оставшийся экран, а курсор больше не попадает
на невидимый рабочий стол. Профиль «Этот Mac» включает дисплей в macOS и возвращает видеовход USB-C.
После смены входа приложение проверяет результат отключения; если macOS
повторно активирует Acer, фоновая проверка отключает его снова. При
переподключении актуальный идентификатор дисплея ищется по его UUID. Поведение можно отключить в настройках.
Изменение действует только пока запущено приложение: после выхода или сбоя
WindowServer автоматически восстанавливает дисплей. Для этой функции используется
приватный API CoreGraphics, поэтому она может потребовать адаптации после крупных
обновлений macOS.

Полная таблица исследованных команд находится в
[`docs/XV282KKV_V11_VCP_REFERENCE.md`](docs/XV282KKV_V11_VCP_REFERENCE.md).

## Реализация

DDC-транспорт использует системные интерфейсы macOS `IOAVService` и адаптирован из открытого проекта [m1ddc](https://github.com/waydabber/m1ddc). Его MIT-лицензия находится в `ThirdParty/m1ddc-LICENSE.txt` и включается в пакет приложения.

## Выпуск версии

Обновите `CFBundleShortVersionString` и увеличьте целочисленный `CFBundleVersion` в `Packaging/Info.plist`. На Mac, в Связке ключей которого находится ключ Sparkle проекта, выполните:

```sh
swift test --build-system native --disable-sandbox
./scripts/package-release.sh
```

Скрипт собирает публичный DMG и проверяет подписи образа и ленты. Создайте тег `v<версия>` на проверенном коммите и опубликуйте оба файла из `dist/v<версия>/` в одном стабильном GitHub Release с пометкой Latest. Для отдельного форка укажите свою ленту и свой открытый ключ Sparkle перед первой сборкой.
