# Acer XV282K KV — подготовка к прошивке

**Архив раннего патча V007.** Он поддерживает только запись EA и использует обратное назначение значений по отношению к V11. Для управления хабом из актуального приложения требуется V11. Само распаковывание и проверка файлов ничего в монитор не записывают.

## Проверка архива

1. Полностью распакуйте архив в локальную папку, например
   `C:\Acer-XV282K-Flash`. Не запускайте updater прямо из ZIP.
2. Откройте PowerShell в этой папке и выполните:

   ```powershell
   powershell -ExecutionPolicy Bypass -File .\VERIFY.ps1
   ```

3. Убедитесь, что у всех пяти файлов написано `OK` и в конце —
   `ALL FILES VERIFIED`.
## Файлы прошивки

- `ORIGINAL_V007.bin` — точный заводской образ для отката.
- `PATCHED_V007_USB_HUB_VCP_EA.bin` — подготовленный образ с Set-VCP `EA`:
  `0` переключает хаб на USB-C, `1` — на USB-B.

Не переименовывайте эти два файла местами. Прошивка занимает около восьми
минут. Во время erase/write нельзя отключать USB, питание монитора или питание
Windows-компьютера.
